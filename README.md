E-Commerce Sales Analysis Dashboard | Power BI

Project Overview

This project focuses on analyzing e-commerce sales data using Microsoft Power BI to understand sales performance, customer purchasing behavior, order trends, and business performance across different categories and geographical locations.

The dashboard provides an interactive view of important business metrics through visualizations and KPI cards, helping users identify sales patterns, monitor order performance, and understand different aspects of e-commerce operations.

The report consists of two dashboard pages, each focusing on different areas of business analysis.

Dashboard Preview

Page 1 – Sales Performance Overview

"Sales Performance Dashboard" (images/sales-performance.png)

This dashboard provides an overview of overall business performance through key performance indicators, including total revenue, total orders, average order value, lost percentage, and total sales.

It also includes visualizations to analyze monthly revenue trends, order distribution by order status, revenue contribution across product categories, and revenue generated by different cities.

Interactive slicers allow users to explore the data by year, category, city, and payment method, making it easier to examine specific segments of business performance.

Page 2 – Order and Customer Behavior Analysis

"Order Analysis Dashboard" (images/order-analysis.png)

The second dashboard focuses on order-related metrics and customer purchasing patterns. It highlights cancellation rate, return rate, average order value, and the number of outlier orders.

The visualizations provide insights into cancellation rates across different payment methods, order distribution by product category and state, weekday-wise ordering patterns, and the most frequently ordered products.

This page helps identify patterns in order cancellations, product demand, and purchasing activity across different segments.

Key Performance Indicators (KPIs)

The dashboard highlights several important business metrics:

- Revenue: 1.88M
- Total Orders: 252
- Average Order Value: 12.77K
- Lost Percentage: 44.9%
- Total Sales: 3.41M
- Cancellation Rate: 23.02%
- Return Rate: 18.7%
- Outlier Orders: 35

These figures represent the values displayed in the dashboard screenshots.

Key Analysis Areas

The project explores monthly revenue trends, category-wise sales performance, geographical revenue distribution, order status distribution, payment-method cancellation patterns, weekday-wise order trends, and product-level ordering activity.

Together, these analyses provide a consolidated view of business performance and help identify areas that may require further attention.

Project Objective

The primary objective of this project is to transform raw e-commerce data into meaningful visual insights. By combining KPIs, charts, and interactive filters, the dashboard makes it easier to monitor business performance and understand sales and order-related trends.

Conclusion

This project demonstrates how Power BI can be used to build interactive business intelligence dashboards for e-commerce analysis. It brings together sales performance, order trends, product demand, and customer-related metrics in a single report, making business data easier to explore and interpret.
